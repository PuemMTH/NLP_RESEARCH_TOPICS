Design การทํ
การทำงาน
า
Estimate Blood loss
1. Main Entry Point (ebl-main/main_fastapi.py):
- เป็น FastAPI server ที่รับ HTTP POST request ที่ endpoint `/ebl`
- รับ input เป็น image file, sponge type และ uid
- เป็น Orchestra ในการสงขอมูลไปยัง services ตางๆผาน RabbitMQ

Code จากส่วนของพี่ปารม ทําแบบ RPC

2. Mask Detection (mask/mask_mmdet.py):
- รับ image จาก main service
- ใช้ Mask2Former model เพื่อ detect สิ่งของในภาพ
- แยก crop แต่ละชิ้นและทํา perspective transform
3. Sponge Classification (sponge/sponge_timm.py):
- รับ cropped images จาก mask service
- ใช้ ResNet18 model แยกประเภทว่าเป็น gauze หรือ swab
- ส่งกลับ labels สำหรับแตละ crop
4. Blood Loss Estimation (estimate/estimate_xgboost.py):
- รับ cropped images และ labels จาก sponge service
- ใช้ XGBoost model แยกตาม type (gauze/swab) เพื่อประเมินปริมาณเลือด
- ส่งกลับค่าประเมินปริมาณเลือดของแต่ละชิ้นและผลรวมทั้งหมด

เปลี่ยนจาก SAM เป็น mmdet
เปลี่ยนจาก pipeline ใหเปน function แยกเปน code
